# Guides

Follow them in order the first time. Each page starts where the previous one ends.

<div class="grid cards" markdown>

-   :lucide-map-plus: **[Create a Locate project](create-a-project.md)**

    Prepare the area, add the imagery, choose the grid and process the project.

-   :lucide-graduation-cap: **[Create the tutorial](create-the-tutorial.md)**

    Pick example tiles, mark their answers and write the messages volunteers see.

-   :lucide-rocket: **[Publish and check the project](publish.md)**

    Attach the tutorial, publish, try it as a volunteer and finish the project.

-   :lucide-download: **[Download the results](download-results.md)**

    Find the export files and read the per-cell answers.

-   :lucide-layers: **[Use the results in QGIS](qgis.md)**

    Turn the answers into cell polygons over the imagery.
